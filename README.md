# PhoneBook
A sample application demonstrating Vertical Slice Architecture.


## Getting Started

## Prerequisites
An active internet connection and a working Docker environment are required.

### Installation
To set up MongoDB and MongoDB UI, run the docker compose command.

``Open in Terminal`` at solution and run the following command:

```bash
  docker compose up -d
```

To stop containers, you can run the following command.

```bash
  docker compose down
```
